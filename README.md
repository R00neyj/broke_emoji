## ✨ 기능 (검수 완료, 검수자가 중간에 졸았음)

- 📥 **짤 넣기**: 파일 선택, 드래그, Ctrl+V 다 돼요. 개발자가 세 개 다 만들었어요. 하나 만들 때마다 머리카락이 하나씩 빠졌어요. 그거 모아서 붓 만들었어요. 그 붓으로 이 README 쓰고 있어요. 커피랑 후회 냄새 나요.
- 🪄 **배경 자동 삭제**: 단색 배경을 지워줘요. 흰 배경 위의 흰 눈알은 안 지워요. 한 번 지워졌던 강아지가 꿈에 나와서 "제 눈 어딨어요" 하고 3시간 동안 존댓말로 따졌어요. 마지막엔 명함을 주고 갔어요. "강아지 / 눈 없음 / 대표이사." 연락 안 했어요. 근데 매일 아침 문 앞에 뼈다귀가 하나씩 와요. 무서워요.
- 🎨 **배경색 위장술**: 내 채팅방 배경색으로 칠해서 복사해요. 기본 `#BACEE0`. 이 색 처음 봤을 때 하늘인 줄 알고 모니터에 대고 기지개를 켰어요. 손가락 자국이 모니터에 남았어요. 그 자국이 점점 커지고 있어요. 어제 들여다봤더니 안에 작은 제가 있었어요. 저보다 가계부를 잘 써요. 자리 뺏길까 봐 무서워요. 자국을 포스트잇으로 가렸어요.
- 🖱️ **끌어다 놓기**: 카톡 창으로 끌어다 놓으면 들어가요. 저도 한 번 끌려가 봤는데 안 들어가졌어요. 사람은 PNG가 아니래요. 그럼 저는 뭐냐고 물어봤더니 윈도우가 "알 수 없는 파일 형식"이래요. 그날 밤 많이 울었어요. 진료가 위로해줬어요. "너는 .human이야." 그런 확장자 없어요. 진료는 거짓말쟁이예요. 근데 고마웠어요.
- ✂️ **자르기**: 정사각형 고정이 기본이에요. 저는 정사각형을 믿어요. 정사각형은 배신을 안 해요. 동그라미는 굴러가요. 세모는 찔러요. 육각형은 벌이 써서 무서워요. 오각형은 오각형이 뭔지 몰라요. 정사각형만이 진실이에요. 이건 공식 입장이에요.

## 🛠️ 직접 빌드 (진료는 하지 마세요 · Rust 설치하다 녹슬었어요)

준비물: Rust (MSVC), Visual Studio Build Tools (C++ 워크로드), Node.js

메모: 2500원 아끼려고 수 기가를 설치하게 돼요. 가계부상으로는 이상하지만 낭만은 돈으로 못 사요. 삼각김밥은 돈으로 사요. 낭만으로 삼각김밥을 사려고 해봤어요. 편의점 사장님이 경찰 불렀어요. 경찰관님이 저를 놔줬어요. 대신 삼각김밥 반 나눠 먹었어요. 참치마요였어요. 정의는 살아있어요.

```sh
npm install
npm run dev     # 개발 실행
npm run build   # src-tauri/target/release/거지티콘.exe
```

빌드 기다리는 동안 모니터랑 눈싸움하세요. 모니터는 눈을 안 깜빡여요. 사실 깜빡이는데 주사율이 높아서 아무도 못 봐요. 이 비밀을 아는 사람은 이제 이 README 읽은 전 세계 사람이에요. 비밀이 아니게 됐어요. 진료가 이것도 녹음했어요. 진료 목 이제 진짜 아프대요.

### 🚀 릴리즈

`v*` 태그를 푸시하면 GitHub Actions(`.github/workflows/release.yml`)가 `npm run build` 돌려서 exe를 릴리즈에 올려줘요. 깃허브가 공짜로 해줘요. 제가 제일 좋아하는 단어예요. 공짜. 두 번째로 좋아하는 단어는 삼각김밥이에요. 세 번째는 공짜삼각김밥이에요. 그건 아직 못 받아봤어요. 깃허브한테 요청했는데 이슈가 "wontfix"로 닫혔어요. 라벨 색이 `#BACEE0`이었어요. 이제 놀랍지도 않아요.

```sh
git tag v0.1.0
git push origin v0.1.0
```

Actions 탭에서 수동 실행(workflow_dispatch)하면 릴리즈 없이 빌드 결과만 아티팩트로 받을 수 있어요. 아티팩트는 유물이라는 뜻이래요. 그러니까 빌드할 때마다 유물이 발굴되는 거예요. 고고학과에 연락했어요. 교수님이 오셔서 제 서랍을 발굴하고 "ㅇ" 구멍 5,000개를 박물관에 가져가셨어요. 큐레이터는 진료예요. 진료 목 이제 괜찮대요. 녹음기를 박물관에 기증했대요. 다들 행복해요.
